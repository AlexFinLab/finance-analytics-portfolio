# Анализ бюджета и фактических логистических расходов

## О проекте

Учебный Excel-проект для анализа логистических расходов
и сравнения бюджета с фактическими затратами.

## Планируемые элементы

- Исходные данные
- Очистка данных
- Расчет отклонений
- Сводные таблицы
- Сводные диаграммы
- Интерактивный Dashboard
- Выводы и рекомендации

## Используемые инструменты

- Microsoft Excel
- Сводные таблицы
- Сводные диаграммы
- Срезы
- Условное форматирование
- Формулы Excel
